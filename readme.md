# PUSH

Push es un lenguaje de programacion de tipado dinamico y multiparadigma, es interpretado, de maquina virtual y compilado a la vez(al menos eso quiero lograr).

# Como funciona?

La idea esque cuando tu ejecutes tu codigo el administrador de paquetes interprete el archivo fuente y los demas si los archivos e interpretan correctamente se llama a la maquina virtual que genera el Push bytecode que luego se interpreta para ser finalmente mostrado de esta manera se logra que no haya errores de sintaxis.

# Lista de logros:

* Interprete ✅
* Maquina Virtual 🟡
* Compilador 🔴
